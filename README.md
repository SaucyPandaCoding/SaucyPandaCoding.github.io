# SaucyPandaCoding website

Official public support and privacy website for Fossil Lab Tycoon.

Static HTML/CSS, no dependencies, no analytics or client scripts. Published with GitHub Pages from the root of main.

- `/` — developer / game home
- `/support.html` — player support and save guidance
- `/privacy.html` — game and website privacy policy
- `/app-ads.txt` — authorized AdMob publisher record

Use Issues for general support. Reports are public: do not post personal or confidential information.
